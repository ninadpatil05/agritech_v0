# 🚀 Deploying Smart Crop Detective to Render.com

This guide covers everything needed to get the app running on Render's free tier.

---

## Prerequisites

- GitHub account with the project pushed to a repository
- Render.com account (free tier works)
- ML model files (`.h5`) hosted at a publicly accessible URL
  - Recommended hosts: **HuggingFace Hub** or **Google Drive** (see Step 4)

---

## Step 1 — Push your repo to GitHub

Make sure all deployment files are committed and pushed:

```bash
git add render.yaml download_models.sh Procfile config.py app.py .gitignore
git commit -m "chore: add Render deployment config"
git push origin main
```

> ⚠️ **Never commit `.env`, `agritech.db`, or `.h5` model files** — they are in `.gitignore`.

---

## Step 2 — Create a new Web Service on Render

1. Go to [render.com](https://render.com) → **New +** → **Web Service**
2. Connect your **GitHub** account and select your repository
3. Render will auto-detect the `render.yaml` Blueprint — click **Apply**
4. If prompted, confirm **Region: Singapore** (lowest latency to India)

---

## Step 3 — Set Environment Variables in Render Dashboard

Go to your service → **Environment** tab and add the following:

| Variable | Value / Notes |
|---|---|
| `FLASK_APP` | `app` |
| `FLASK_DEBUG` | `false` |
| `SECRET_KEY` | Auto-generated by Render ✅ |
| `JWT_SECRET` | Auto-generated by Render ✅ |
| `JWT_EXPIRES_HOURS` | `72` |
| `GEMINI_API_KEY` | Your Google AI Studio key |
| `OPENWEATHER_KEY` | Your OpenWeatherMap API key |
| `DB_PATH` | `/tmp/agritech.db` |
| `MODEL_PATH` | `/tmp/models` |
| `PLANT_MODEL_URL` | Direct download URL to `plant_validator_model.h5` |
| `DISEASE_MODEL_URL` | Direct download URL to `crop_disease_model.h5` |
| `BLUR_THRESHOLD` | `100` |
| `CONFIDENCE_THRESHOLD` | `0.65` |
| `CONTACT_SMTP_HOST` | e.g. `smtp.gmail.com` |
| `CONTACT_SMTP_PORT` | `587` |
| `CONTACT_SMTP_USER` | Your Gmail / SMTP address |
| `CONTACT_SMTP_PASSWORD` | Gmail App Password (not your regular password!) |
| `CONTACT_MAIL_TO` | Email to receive contact form submissions |
| `LOGS_TOKEN` | Auto-generated by Render ✅ |

---

## Step 4 — Host your `.h5` Model Files

The `.h5` model files are too large for Git. Host them externally and set the URLs above.

### Option A — HuggingFace Hub (Recommended)
1. Create a free account at [huggingface.co](https://huggingface.co)
2. **New Model** → upload both `.h5` files
3. Set the model repository to **Public**
4. Copy the **raw download URL**:
   ```
   https://huggingface.co/<username>/<repo>/resolve/main/plant_validator_model.h5
   https://huggingface.co/<username>/<repo>/resolve/main/crop_disease_model.h5
   ```
5. Paste these as `PLANT_MODEL_URL` and `DISEASE_MODEL_URL` on Render

### Option B — Google Drive
1. Upload each `.h5` file to Google Drive
2. Right-click → **Share** → "Anyone with the link"
3. Get the file ID from the share URL: `https://drive.google.com/file/d/**FILE_ID**/view`
4. Construct the direct download URL:
   ```
   https://drive.google.com/uc?export=download&id=FILE_ID
   ```

> ⚠️ Google Drive sometimes redirects large files through a virus-scan page. HuggingFace is more reliable for `curl` downloads.

---

## Step 5 — Deploy

1. Render will automatically trigger a build on every `git push` to `main`
2. Monitor build logs: **Render Dashboard** → your service → **Logs** tab
3. The build command runs:
   ```bash
   pip install -r requirements.txt && bash download_models.sh
   ```
4. Once the build succeeds your app will be live at:
   ```
   https://smart-crop-detective.onrender.com
   ```

## ⚠️ Known Limitations on Free Tier

| Issue | Why | Fix |
|---|---|---|
| **SQLite resets on redeploy** | Free tier has no persistent disk — `/tmp` is ephemeral | Migrate to **Render Postgres** (free add-on) or use a **Render Disk** (paid $1/mo) |
| **Models re-downloaded every build** | `/tmp` is cleared between deploys | Same solution: persistent disk, or accept the ~30s download at build time |
| **Cold starts (15 min spin-down)** | Free tier sleeps after inactivity | Expected — upgrade to Starter plan ($7/mo) to avoid |
| **SMTP blocked on some ports** | Cloud providers often block port 25 | Use **Gmail App Password** on port 587 (already configured) |
| **`.h5` files can't be in Git** | GitHub 100MB file limit | Hosted externally via `PLANT_MODEL_URL` / `DISEASE_MODEL_URL` |

## Gmail App Password Setup (for contact form)

1. Go to your Google Account → **Security** → **2-Step Verification** (must be enabled)
2. Search for **App passwords** → create one for "Mail"
3. Use that 16-character password as `CONTACT_SMTP_PASSWORD`
4. Set `CONTACT_SMTP_HOST=smtp.gmail.com` and `CONTACT_SMTP_PORT=587`

---

## Checking Logs

The app exposes a protected log-tail endpoint. Hit it with your `LOGS_TOKEN`:

```bash
curl -H "X-Admin-Token: YOUR_LOGS_TOKEN" https://your-app.onrender.com/api/logs
```
